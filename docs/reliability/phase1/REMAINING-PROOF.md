## Scope discipline

The priority is the future reliability consequence, not a claim that an active Production incident exists. Phase 1 did not read current Production state. Infrastructure outage causation remains separate from the reproduced application query defect. New evidence must be attached at its own proof layer; source inspection, synthetic SQL and physical observations cannot silently substitute for one another.

The recommended next single implementation phase is [score critical-path hardening](NEXT-PHASE.md). Infrastructure/restore evidence remains a mandatory readiness dependency, even though a provider change is not recommended from these local measurements.
