## Remaining implementation boundary

The preserved retirement design identified several Preview capabilities as absent from the canonical adapter. Treating Production identity as Preview or relaxing the protected operation boundary would weaken authority. The owner authorizes minimum replacements. The audit found that Preview bulk importers are not equivalent to the existing canonical entry/auction/setup commands, and a new parallel Round Control/financial engine would change established contracts. Odds had an existing compatible canonical primitive and was completed. The remaining safe implementation requires sharing the canonical operation context and ledgers described in [design review](CANONICAL-ADAPTER-DESIGN-REVIEW.md); PARTIAL reflects missing required work, not optionality or lack of authorization.
