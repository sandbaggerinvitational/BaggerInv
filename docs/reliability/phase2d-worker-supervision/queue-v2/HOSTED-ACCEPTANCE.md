## Cost and provider contract

The [official Queues overview](https://vercel.com/docs/queues) documents a beta on
all plans. [Regional pricing](https://vercel.com/docs/pricing/regional-pricing)
lists queue operations at $0.60–$0.96/million; [metering rules](https://vercel.com/docs/queues/pricing)
include size increments and doubled units for idempotent sends. Actual
account availability, free allowance, limits and billing remain UNKNOWN until the
read-only hosted gate. No new fixed resource cost was incurred locally.

Illustrative operation-only estimate: 120 tiny ticks × 8 assumed queue operations ×
$0.60/million = $0.000576, excluding retries and billable payload increments. Actual
operation count must be measured, not asserted. A three-day 4,320-tick illustration
under the same assumption is $0.020736, plus function compute, database, networking
and logs. The authorized supervisor still requires a new explicit finite window
every two hours; this illustration is not authority for a three-day schedule.

The [SDK reference](https://vercel.com/docs/queues/sdk) and installed 0.7.0 source
were reviewed for delay, explicit deployment pin, finite retry and idempotency.
No physical message cancellation is used. Documented private transport is not
claimed locally as observed private hosted transport.
