# Separate hosted staging proof requirements

**This task creates no staging deployment and grants no Production authority.** A local PASS would permit owner review of a later isolated-staging certification request only.

1. Confirm isolated project, database identity, synthetic data and outbound communication suppression before any mutation.
2. Install121→122→123→124 on a restored/sanitized predecessor shape, including pending jobs and existing receipts. Preserve certifications and use supported reviewed recertification; migrations intentionally stop on existing annual certifications.
3. Prove service-only RPC grants, RLS, fixed search paths, private Auth-UUID storage, current identity reassociation denial, token/cookie transport and distributed abuse protection.
4. Verify actual server/database UTC timestamp responses against unchanged Build10 decoder; the retained decoder's offset-timezone failure is a known gate, not a fixed native defect.
5. Exercise actual score and recovery endpoints, all formats, duplicate/conflicting mutations, Lock/Resume/Finalize and lost acknowledgement across process replacement.
6. Provide a hosted worker supervisor with secrets isolation, least authority, scheduler health, bounded concurrency and crash recovery. Run current-source convergence, terminal recovery and compatible-release backlog cases for every automatic family.
7. Run432holes with worker interruption, lease expiry, tight timeout and final current-result parity. Owner-approved NetSkins processing/publication remain explicit.
8. Measure finite timeout, connections, I/O and resource headroom on the actual hosted profile. Local p99 is not the hosted budget.
9. Rehearse additive-function/application rollback without deleting authored receipts or durable work, and certify mixed processor versions before rollout.

Production requires a **separate explicit owner authorization** after these proofs and rollback review. Production smoke must not create fake tournament scores, change historical financial data, or run load/chaos tests.
