## Negative environment and failure injection

The test runner removes provider credentials from child environments and preloads a net/tls/socket guard denying remote destinations. Boot additionally permits no real environment files and supplies only synthetic nonfunctional Supabase configuration. It does not inherit a developer Google account. Two harness selftests prove provider sockets are denied and historical output writes are redirected.

Credential absence, absent Sheet IDs and absent archive workers are normal in the fixture. Actual runtime transport entrypoints throw GOOGLE_RUNTIME_RETIRED before delivery, public CSV access is guarded before cache, and retired HTTP cron returns 410. The 432-hole score loop uses an unavailable-Google scope and asserts 0 adapter attempts; actual SQL verifies 0 new Google jobs. These are stronger than merely seeing no successful external request. Together with source inspection, these tests show the retired consumer is not required by the exercised score path; they do not prove every hosted network failure scenario.

Local compiled boot/mobile health passes; it does not establish real database connectivity or global worker health. Retired Google delivery is excluded from the candidate health contract. Unavailable required telemetry remains NOT_OBSERVED; a successful local health route does not certify every health signal. Optional CMS/messaging contracts with incomplete parity remain explicit in the register. No supported optional Google export remains; there is no export retry system being certified.
